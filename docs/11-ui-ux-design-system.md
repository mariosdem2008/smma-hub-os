# 11 UI UX Design System

## 1. Experience Standard

SMMAHUB should feel premium, operational, and trustworthy. It should reduce perceived complexity without hiding important controls.

## 2. UX Principles

- Show workflow state clearly.
- Keep context near the work it informs.
- Make risk and approvals visible, not buried.
- Prefer structured forms over ambiguous text when data quality matters.
- Use progressive disclosure for advanced governance controls.

## 3. Core Interface Patterns

| Pattern | Purpose |
|---|---|
| Status rails | Show workflow state, blockers, and owners |
| Evidence panels | Show retrieval sources, assumptions, and missing context |
| Approval cards | Present decision, deadline, rationale, and history |
| Pack selectors | Show which packs are active and why |
| Audit drawers | Reveal AI run details without cluttering primary flows |

## 4. Visual Standard

- Premium but not decorative.
- Dense enough for operators, clear enough for clients.
- Use hierarchy to distinguish truth, drafts, and generated suggestions.
- Treat warnings, risk flags, and missing-context notices as first-class UI states.

## 5. Client Portal Principles

- The portal must feel cleaner than the internal workspace.
- Clients should always know what needs a decision, what is in progress, and what changed.
- Avoid exposing internal AI or workflow jargon to clients unless it adds trust.
