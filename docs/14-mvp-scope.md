## 1. MVP Goal

Prove that SMMAHUB can encode a Tier 2 agency's expertise, hold durable client context, generate governed strategy, and move work through reviewable execution.

## 2. In Scope

- agency setup for standards, offers, approvals, and baseline packs
- client operating records
- source ingestion for core canonical documents
- strategy brief generation with grading
- work item creation and approval handling
- basic client portal collaboration
- audit logging for AI runs and decisions

## 3. Must-Prove Flows

1. An agency can encode its operating model.
2. A client can be onboarded into a durable record.
3. AI can generate a grounded strategy brief from approved context.
4. Work can move through approval without losing state.
5. A client can review, respond, and stay oriented.

## 4. MVP Constraints

- No generic CRM ambition.
- No broad publishing suite.
- No freeform automation builder.
- No finance-heavy PSA layer.
- No deep analytics platform.
- No non-ICP enablement scope, low-end workflows, or no-cost funnel.

## 5. Definition Of Done

The MVP is done when a pilot agency can run live client work without repeatedly rebuilding context and without bypassing governance.
