# Source Catalog

## 1. Purpose

This appendix defines the major source categories SMMAHUB should ingest and govern.

## 2. Source Categories

| Source type | Typical owner | Canonical use |
|---|---|---|
| Agency operating doc | Agency owner | Positioning, services, SOPs, rules |
| Client onboarding form | Account lead | Business facts and goals |
| Brand guideline | Client or strategist | Voice, claims, visual and messaging constraints |
| Offer document | Strategist | Service and commercial logic |
| Transcript or meeting note | Account lead | Nuance, decisions, evolving context |
| Performance report | Manager | Evidence for reporting and optimization |
| Approved content artifact | Agency reviewer | Trusted exemplar or historical record |
| Approval record | Internal or client approver | Decision and rationale trail |

## 3. Catalog Rules

- every source needs provenance and freshness metadata
- generated artifacts do not become canonical without explicit promotion
- conflicting sources must remain inspectable
- source changes should trigger downstream revalidation where needed
