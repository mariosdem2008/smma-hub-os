## 1. Principle

SMMAHUB should teach agencies better operational discipline while delivering value quickly.

## 2. Design Principles

1. Show value before demanding heavy setup.
2. Translate complex governance into simple actions.
3. Reveal the next best step, not every possible control.
4. Preserve expert control for advanced users.
5. Make mistakes recoverable and visible.

## 3. Onboarding Learning Model

| Stage | User need | Product response |
|---|---|---|
| First contact | Understand what the product does | Clear category framing and guided setup |
| Early setup | Learn what information matters | Templates, examples, and validation cues |
| First outcomes | See proof quickly | Strategy draft, readiness audit, visible workflow state |
| Habit formation | Build trust | Stable approvals, auditability, and repeatable outcomes |

## 4. AI Interaction Principles

- Explain what context was used.
- Show why an output was blocked or downgraded.
- Surface missing context instead of hiding uncertainty.
- Teach users how stronger records improve future outputs.
