## 1. Feature Progression

| Capability | MVP | V1 | V2 |
|---|---|---|---|
| Agency setup | Basic governed setup | Rich templates and validation | Benchmarking and optimization |
| Client operating record | Core fields and sources | Deeper enrichment and health scoring | Predictive drift detection |
| Subject packs | Manual creation and approval | Templates and version analytics | Adaptive recommendations |
| Strategy generation | Governed brief generation | Multi-step strategy workflow | Specialist strategy agents |
| Execution spine | Tasks, briefs, approvals | Dependencies and richer scheduling | Cross-client capacity intelligence |
| Client portal | Approvals, requests, files | Rich collaboration and contextual messaging | Shared planning and insights |
| AI evaluation | Core grading and audit | Expanded rubric and reviewer tooling | Continuous quality learning loops |
| Integrations | Minimal launch-critical set | Core agency stack integrations | Broader ecosystem |

## 2. Release Logic

- MVP proves the governed operating model for a real Tier 2 agency team.
- V1 improves operational scale, usability, and repeatability across 5-25 active clients.
- V2 introduces more specialized intelligence and optimization after the core operating workflows are deep enough for expert operators.
