# SMMAHUB Docs

## Status

This docs tree was intentionally reset on 2026-03-23.

The previous documentation set had become too large, too repetitive, and too optimistic. It mixed strategic drafts, implementation plans, audit deltas, readiness claims, and overlapping product narratives in a way that made the repo look more complete than it really is.

That is no longer the standard.

## Product Truth

The authoritative product-direction document is:

- `docs/vision/SMMAHUB_MASTER_VISION_AND_PRODUCT_STANDARD_2026-03-23.md`

If any future note, audit artifact, or implementation memo conflicts with that file, the master vision wins.

## What Remains In `docs/`

- The master vision document
- Raw evidence artifacts
- Machine-readable schemas and JSON contracts
- SQL drafts and supporting technical artifacts

These remaining files are support material. They are not allowed to redefine the product.

## What Was Removed

- old plans
- old visions
- old readiness and launch claims
- overlapping audit narratives
- migration blueprints and implementation programs that were no longer acceptable as product truth

## Standard Going Forward

Every future product document must:

1. say whether it describes current reality, target reality, or evidence only
2. reinforce the real end-state platform instead of a narrow feature story
3. avoid implying that route coverage or isolated green tests mean the business is ready
4. help close the gap between the repo and the actual high-ticket product vision
